## Português

### Novas funcionalidades

- Centro de Ajuda com documentação funcional alargada, pesquisa, temas agrupados e índice em cada página, com conteúdos de administração apresentados de acordo com as permissões do utilizador.
- Aviso persistente sobre a privacidade dos dados enviados para fornecedores de IA na nuvem, integrado no sistema de notificações.

### Correções

- A confirmação do aviso de privacidade da IA mantém o utilizador na página atual.
- Notificações simultâneas são apresentadas em conjunto e os avisos persistentes permanecem visíveis até serem dispensados.
- Ícone de lembretes da barra superior atualizado para melhorar a consistência visual.

## English

### New features

- Help Center with expanded functional documentation, search, grouped topics and a table of contents on each page, with administration content shown according to user permissions.
- Persistent privacy warning about data sent to cloud AI providers, integrated into the notification system.

### Fixes

- Acknowledging the AI privacy warning keeps the user on the current page.
- Simultaneous notifications are displayed together and persistent warnings remain visible until dismissed.
- Updated the top-bar reminder icon for improved visual consistency.
